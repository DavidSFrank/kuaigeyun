这些不是一份说明书，而是菜单对应的前后端代码。按你那套步骤对上路径如下。

**前端页面**（`riveredge-frontend/src/apps/kuaiiot/`）

| 菜单 | 页面 |
|---|---|
| 接入配置 | `pages/connections/index.tsx` |
| 产品模型 | `pages/products/index.tsx` |
| 设备连接 | `pages/devices/index.tsx` |
| 点位映射 | `pages/tags/index.tsx` |
| 数采链路 | `pages/pipeline/index.tsx` |
| 数采中心 | `pages/dashboard/index.tsx` |
| 边缘配置（可跳过） | `pages/edge-configs/index.tsx` |

接口封装：`services/kuaiiot.ts`  
菜单入口：`riveredge-backend/src/apps/kuaiiot/manifest.json`（前端路由 `/apps/kuaiiot/...`）

**后端**（`riveredge-backend/src/apps/kuaiiot/`）

| 做什么 | 主要文件 |
|---|---|
| 接入配置 / MQTT / 消息体 | `api/connections.py`，`services/connection_service.py`，`services/mqtt_subscriber_service.py`，`services/mqtt_paho_bridge.py`，`services/mqtt_message_buffer.py` |
| 产品模型 / 内置 `sanyi_plc_line` | `api/products.py`，`services/product_service.py`，`tag_templates.py` |
| 设备连接 / 外部设备 ID 名录 | `api/` 里设备接口，`services/device_service.py`，`services/mqtt_device_discovery.py`，模型 `models/iot.py`（`IotDevice`、`IotDiscoveredMqttDevice`） |
| 点位映射 | 点位 API + `services/tag_apply_helper.py`（套产品模型时生成） |
| 数采链路 | `services/pipeline_service.py` |
| 三易报文拍平 | `services/sanyi_line_adapter.py` |
| 边缘配置 | 边缘相关 API/服务（你这套 MQTT 不用碰） |

**库表（迁移）**

- 最近消息：`migrations/models/826_20261004060000_kuaiiot_connection_messages.py` → 表 `apps_kuaiiot_connection_messages`
- MQTT 设备名录：`migrations/models/827_20261004080000_kuaiiot_discovered_mqtt_devices.py` → 表 `apps_kuaiiot_discovered_mqtt_devices`

点「加载内置产品」读的是 `tag_templates.py` 里的 `sanyi_plc_line`，不是单独再有一个 JSON 文件。
